# Баннеры владельца

Положите сюда файл с одним из имён — он сам встанет фоном карточки на главной
(после `scripts/design/build_photos.py`; выкладка — `deploy/release.sh`):

| Файл | Где | Размер (px) | Видно на экране (CSS px) |
|---|---|---|---|
| `hero_buy.webp` | карточка «Хочу приобрести машину» | 1110 × 600 | 370 × 200 |
| `hero_check.webp` | тёмная карточка «Проверить конкретную машину» | 1110 × 600 | 370 × 200 |
| `battle_bg.webp` | фон каждой карточки «Битвы поколений» | 516 × 510 | 172 × 170 |

Формат: WebP (подойдут PNG и JPG — тогда то же имя с .png / .jpg), sRGB, без прозрачности, до 250 КБ
(battle_bg — до 120 КБ). Свободные зоны и подробности — в ответе в чате / отчёте.
