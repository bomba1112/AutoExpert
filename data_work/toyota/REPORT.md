# Toyota Camry (США, MY2014–2026): отчёт по разделу 10 промта

Дата: 2026-10-02. Линейка 1 из 5 (ОСТАНОВКА = после первой линейки). Данные записаны в рабочую БД `autoexpert.db` (Alembic `f087_us_tech_scoped_facts`).

**Главное:**
- **Факты.** В базе 342 технических факта по Camry с цитатами и страницами источников, плюс 642 записи по 42 конфигурациям EPA.
- **Безопасность.** 22 recalls NHTSA, 14 известных проблем с основаниями.
- **Видимость.** Публикации в приложение нет: каталог, claims и ревизии не изменены, в приложении по-прежнему 644 конфигурации.
- **Нет регламента ТО.** Книжки ТО Toyota заблокированы из AZ.
- **Нет руководств за 2024–2026 годы** и большинства гибридных руководств.

**Ограничение.** Официальные PDF Toyota на `assets.sipb.toyota.com` (руководства и Warranty & Maintenance Guide) отдают «The Amazon CloudFront distribution is configured to block access from your country». Обход гео-блокировки не применялся. По правилу Приложения B вместо них взяты копии руководств с carmans.net со статусом SECONDARY. Вторичные справочники (auto-data.net, CarComplaints, Dashboard Light) не понадобились, потому что официальных спецификаций хватило.

- Одно уточнение: в спецификации 2018 года 203 л.с. и 184 lb-ft указаны для LE/SE/XLE, комплектация L появляется только с 2019 года. Применимость за 2018 год сужена.

## 6. Изменения схемы
- `f087_us_tech_scoped_facts` (коммит `62024c8`):
  - `technical_evidence` и `known_issues`: колонки области действия (уровень, поколение, ключ двигателя/коробки, годы, `display_level`, `natural_key`), `vehicle_variant_id` стал nullable;
  - новая таблица `maintenance_schedule_items`.
- Все существующие читатели фильтруют по `vehicle_variant_id`, поэтому новые строки для текущего кода невидимы.
- Downgrade обратим и отказывается работать, если есть строки без конфигурации.
- Репетиция на копии: upgrade 9,5 с, downgrade 7,0 с.
