# Карта дизайн-референса → экраны и данные Auto Expert

Источник: `design/reference/01–04*.png` (картинки владельца). Цифры и названия на картинках — **примеры**;
значения берутся только из базы. Колонка «Данные» — откуда заполняется блок у нас; «нет» — блока нет
в данных, он не показывается.

## 01 — утверждённый: главная · подбор · подходящие варианты

### Главная (01, слева; тёмный вариант — 03, слева)
| Блок сверху вниз | Что в блоке | Данные |
|---|---|---|
| Шапка | логотип AUTO EXPERT, подпись региона (только AZ), колокольчик (лента гаража), кружок профиля | регион пользователя; лента — `/garage/feed` |
| Заголовок | «Твой честный автоэксперт без предвзятости», подзаголовок | текст |
| Карточка «Хочу приобрести машину» | текст, кнопка «Начать подбор», чипы Бюджет · Двигатель · Коробка · Кузов · Рынок | → подбор |
| Карточка «Проверить конкретную машину» | VIN / госномер / объявление, одно поле + кнопка, чипы (что проверяем) | VIN → vPIC; ссылка → мнение по объявлению; госномер — нет источника (честно) |
| «Битва поколений» | курируемые пары «A vs B», подпись, «Все сравнения» | конфиг `battles.json` (владелец редактирует) + каталог |
| Нижнее меню | Главная · Сравнения · Проверить · Мои отчёты (+ Гараж) | — |

Регион: AZ — бюджет в AZN, упоминания Turbo.az, подпись «Azerbaijan»; US/EN — бюджет в $, без Turbo.az и без подписи.

## 02 — карточка машины · Техническая часть · Двигатель → Масла и жидкости
| Экран / блок | Что | Данные |
|---|---|---|
| Шапка карточки | фото, «Toyota Camry», «2020 • USA» | вариант / конфигурация |
| Чипы | Седан · 5 мест · Бензин · 2.5 · AT · FWD | факты варианта (пустые — скрыты) |
| Короткие строки | Рынок, Поколение, Топливо (АИ), Разгон | профиль; разгона в базе нет → строка скрыта |
| Вкладки | Техническая часть · Слабые места · Сервисные кампании · Что проверить | US-база: категории, weak_points, campaigns, чек-лист |
| «Техническая часть» | список категорий со стрелками: Двигатель, Коробка, Топливо, Впрыск и наддув, Масла и жидкости, Кузов и размеры, Подвеска и тормоза, Салон | категории `us_tech_facts.build` (только непустые) |
| «Двигатель → Масла и жидкости» | блоки «Двигатель» (код, тип, масло, допуск, объём, интервал) и «Коробка передач» (тип, жидкость, объём, регламент) | факты масла/ATF + регламент ТО конфигурации; вторичные — с пометкой |
| Сноска | «Все данные относятся к выбранной версии…» | текст |
| Кнопка | «Добавить в мой гараж» | → гараж (garage_v1) |

## 03 — сравнение с вердиктом (в центре)
| Блок | Что | Данные |
|---|---|---|
| Две машины «VS» | фото, название, год · объём · топливо, плашка | члены сравнения |
| «Вердикт Auto Expert» | короткий вывод, «Читать полный вывод» | `compare.verdict` |
| «Главное за 30 секунд» | Надёжность · Комфорт · Расход · Стоимость обслуживания · Ликвидность | только строки с данными: расход (EPA), слабые места/кампании (надёжность), ТО (обслуживание); комфорт/ликвидность — нет данных → строка скрыта |
| «Ориентировочные расходы на 2 года» | сумма по машине, разбивка | расчёт стоимости с настройками по умолчанию (Баку, 1 000 км/мес, 24 мес), «Изменить условия» свёрнуто |
| Низ | «Проверить VIN / госномер» | → проверка |
