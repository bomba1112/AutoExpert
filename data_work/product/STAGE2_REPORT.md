| 1. Добавить машину | По VIN или из каталога (марка → модель → год → конфигурация). VIN расшифровывается по **локальной** базе NHTSA vPIC: файл `vPICList_lite_2026_09.plain.zip`, 72,6 МБ, с vpic.nhtsa.dot.gov/downloads, переведён в SQLite `C:\AutoExpertData\vpic\vpic_lite.sqlite`. В git его нет, внешних запросов нет. Логика перенесена из процедуры NHTSA `spvindecode`. VIN сужает выбор: Camry 2020 — 2 конфигурации из 4, Sonata 2018 — ровно 1, BMW 2016 — 3 из 10. |
| 2. Пробег | Ввод пробега и среднего пробега в месяц. Текущий пробег оценивается. Если с замера прошло 30 дней или оценка выросла на 2 000 км, приложение просит уточнить. |
| 3. Масло | Интервал задаёт владелец. Подсказка — значения из руководства (обычные и тяжёлые условия) и бортовая система. |
| 4. Журнал | Следующая замена считается от записи: км и месяцы, «что раньше», первая и последующие замены. |
| 5. «Не знаю» | Считается по регламенту от текущего пробега с пометкой «по регламенту, не подтверждено». Для ремня ГРМ — «рекомендуем проверить сейчас». |
| 6. Условия | AZ и СНГ по умолчанию — тяжёлые (если в руководстве есть отдельный регламент), США — нормальные. Владелец переключает. |
| 7. Бортовые системы | Oil-Life, CBS, Maintenance Minder: «по сигналу бортовой системы; не позже …» по предельному сроку из руководства. Кнопка «Машина просит ТО» сбрасывает отсчёт. |
| 8. Подсказки | Recalls по конфигурации и году. Суточная проверка NHTSA: код и `scripts/garage_recall_job.py` для cron. Новые кампании хранятся отдельно и в базу фактов не пишутся. Известные проблемы показываются; типичный пробег — если он есть в данных. Ближайшее ТО — с жидкостью и объёмом. |
| 9. Уведомления | Лента «Моя машина» в приложении; уведомление, причина которого исчезла, помечается прочитанным. Push — только интерфейс `PushSender`, сейчас ничего не отправляется. |
| 10. PDF | «Журнал обслуживания» с пометкой, что записи внёс владелец и приложение их не проверяло. |
| 11. Тесты | 25 тестов `backend/tests/test_garage.py`: все варианты интервалов, «не знаю», условия, бортовые системы, recalls по конфигурации, HIDDEN_CONFLICT не используется, флаг, чужая машина недоступна. Web — 2 теста. |

## Что видно на трёх машинах — пробелы данных, не кода
- **Camry 2020:** в базе нет регламента ТО — книжки Toyota заблокированы из AZ, это известно ещё по раунду 1. Работают масло по интервалу владельца, журнал, 3 recall, 4 проблемы, жидкости и объёмы (ATF WS 7,3 л; ОЖ 6,9 л; масло 0W-16 4,5 л).
- **Sonata 2018 (LF):** регламента нет — на официальном сайте Hyundai только DN8 с 2020 года. Жидкостей в карточке нет. Есть 1 recall и известные проблемы.
- **BMW 3 Series 2016:** регламент — только 3 пункта CBS (SECONDARY_NOTE), все «по сигналу бортовой системы». По маслу есть только данные о доливке.
- **Типичный пробег проблем** (CarComplaints) в базе пока не заполнен ни у одной записи. Код его покажет, как только он появится.

## Решения, которые я принял сам — прошу подтвердить
1. **«Не знаю».** Следующая замена — ближайшая точка сетки регламента после текущего пробега (при 87 000 и интервале 30 000 → 90 000), а не «текущий + интервал» (117 000). Так безопаснее при неизвестной истории. Месяцы — от даты ответа, а если известна дата начала эксплуатации — по сетке от неё.
2. Если в руководстве нет отдельного регламента для тяжёлых условий, показывается обычный с пометкой.
3. Вопросы «когда меняли?» в форме — постоянный список из 8 работ. Ответы «не знаю» по работам, которых нет в регламенте машины (ремень ГРМ на цепном моторе), сервер не сохраняет.
