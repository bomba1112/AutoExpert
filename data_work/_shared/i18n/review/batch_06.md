## Most serious errors

1. **`cc1091fbbe3b` ru + az (Accord Hybrid fail-safe mode):** the car runs only on battery power, and the battery was "аккумулятор / akkumulyator". In this glossary that word is the 12 V battery, so a reader would think the car drives on the 12 V battery until it goes flat. It is now "батарея / batareya", the high-voltage battery. The speed was also given only as "40 милями в час / saatda 40 mil". The glossary units convention requires the km/h value, so it is now "40 миль/ч (64 км/ч)" / "40 mil/saat (64 km/saat)". The same battery fix was made in `9236da1c0e52` and `c46b8e5d20fa` (Kona/Ioniq Electric Li-ion battery).
2. **`f056cdd66752`, `50ce17875092`, `ef8333219be1` ru:** "replacement" was rendered as "сменный двигатель", "сменная рулевая рейка" and "сменные запасные части". "Сменный" means interchangeable, the same error batch 05 fixed in `6bb40824b66c`. The texts now say what happened: the engine or rack was replaced ("был заменён двигатель", "была заменена рулевая рейка"), and the defect is in the unit that was installed.
3. **`442ed5a0e208` ru + az:** "(подключаемый гибрид)" / "(şəbəkədən doldurulan hibrid)" was added after the model name "Sonata Plug-In Hybrid". This is text the source does not have, and batch 03 kept "Optima Plug-in Hybrid" without it. It was removed. The RU list is now in parentheses, like the other multi-model items.
4. **Wrong part or wrong defect named:**
   - `1931fe5cd544` ru + az: "crankshaft pin" was "шейка коленчатого вала / dirsəkli valın boynu", which can mean any journal. It is the crankpin: "шатунная шейка / şatun boynu".
   - `0b26c4f3b9c5` ru: "обогрев ветрового стекла" names an electrically heated windshield. The FMVSS 103 defroster is "система удаления наледи", the same fix as batch 05 `a77da39699a3`.
   - `314b272000b4` ru + az: the door striker was "скоба / skoba". Batch 03 `32f8c9888e1b` used "ответная часть замка / kilidin qarşı hissəsi".
   - `6885cd768499` ru: "insufficiently welded" became "с недостаточным проваром", which adds a specific welding diagnosis (lack of penetration) that the source does not make.
   - `903fe2797224` ru: "may have degraded the coating" became "могла разрушить" (destroy). It is now "повредить".
5. **Glossary terms not used, or calques:**
   - `db00c3439c97`: "потере усиления со стороны электроусилителя руля" and AZ "elektrik sükan gücləndiricisinin köməyinin itməsi" are now the glossary forms "потеря усиления руля / sükan gücləndirməsinin itməsi". The unit has one name, "электроусилитель руля / elektrik sükan gücləndiricisi".
   - `63a2c1a5c09e` ru: "болт, крепящий ремень" is now the glossary "точка крепления ремня безопасности" (seat belt anchorage).
   - `dff48c76a850`: "раскрытие без предупреждения / xəbərdarlıqsız açılma" was a calque of "deploy without warning"; it is now "внезапное раскрытие / gözlənilmədən açılma".
   - `47edc4d54c9f` az: "qarşısını ala bilməyə bilər" stacked two modal 'bil-' forms; it is now "qarşısını almaya bilər".
   - `30b90e3b79d4` ru: "могло не содержать надлежащим образом необходимую информацию" was ungrammatical.
